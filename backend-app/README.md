# Multi-Module Job Scheduler & File Manager

A robust, enterprise-grade full-stack application for managing background tasks and file uploads with real-time monitoring.

## 🚀 Features

- **Real-time Job Monitoring**: WebSocket-integrated dashboard for live task updates.
- **Background File Processing**: Resilient file upload system with persistent progress tracking.
- **Priority Queue**: Server-side job worker with priority levels and automated retry logic.
- **Clean Architecture**: Standardized module structure and consistent naming conventions.

## 🛠️ Tech Stack

- **Frontend**: React, TypeScript, Vite, Ant Design, Redux Toolkit, Socket.io-client.
- **Backend**: Node.js, Express, TypeScript, Mongoose, Socket.io, Multer.

## 📦 Project Structure

```bash
.
├── backend/          # Node.js Express Server
├── frontend/         # React Application
└── README.md         # Project documentation
```

## 🚥 Getting Started

### 1. Backend Setup

1. `cd backend`
2. `npm install`
3. `npm run dev`

### 2. Frontend Setup

1. `cd frontend`
2. `npm install`
3. `npm run dev`
